# LibNodeGraphStd

## Summary

Standard math, logic, and flow nodes registered into a LibNodeGraph registry. No window of its own.

## Description

LibNodeGraphStd registers the standard math, logic, and flow nodes into a LibNodeGraph registry. Watchdog uses those nodes. This library draws no window of its own.
