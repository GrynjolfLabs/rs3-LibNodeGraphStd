<h2>LibNodeGraphStd</h2>
<p>LibNodeGraphStd registers the standard math, logic, and flow nodes into a LibNodeGraph registry. Watchdog uses those nodes. This library draws no window of its own.</p>

<h2>Data Protection</h2>
<p>LibNodeGraphStd stores nothing and sends nothing. Node values exist in memory only while a graph is running. This information is not transmitted outside of the plugin under any circumstances.</p>
